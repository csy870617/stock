# 사전 등록 — '현재 추세'의 소급 변경(다시 그리기): 확인일만 바로잡을까, 판정이 다시 그려지지 않게 바꿀까 (2026-11-07, 결과를 보기 전에 씀)

사용자 요청(2026-11-07): "추세 전환이 뭔가 이상한 것 같아. 다시 한 번 심도 있게 연구하고 수정이 필요하면 수정해줘."

## 결과 전에 확인한 사실
- `data/trend-summary.js` git 이력 48회(2026-10-24 ~ 11-07, 약 100종목): 판정(상승·하락)은 그대로인데 **확인일만 바뀐 경우 13건**
  (AMP 9/24 → 10/19 → 9/24, MA 7/2 → 7/16 → 7/2, 삼성바이오로직스 10/23 → 10/30), 시작점이 1년 가까이 옮겨 간 경우(KT&G 2025-03-14 → 2026-03-04).
  판정 변경 17건 중 몇 건이 가격 되돌림이 아니라 기준 폭 변화 때문인지는 아직 모른다.
- 원인 가설: 전환폭 h = clamp(10·σ, 10%, 35%)(σ = 직전 500거래일 일간 로그수익 표준편차)를 **매일 그날 σ 로 정하고 750거래일 창 전체를
  다시 지그재그로 그린다**(`scripts/lib-trend.js` analyze·regime). σ 가 조금 변하면 과거 전환점·확인일이 소급해서 바뀌고, 판정 방향도
  가격 움직임 없이 뒤집힐 수 있다. 연구(`../trend-method`·`../trend-follow`)도 같은 방식(그날 σ 로 그날 창을 계산 — 미래 자료는 안 씀)이라
  '그날의 판정'은 검증과 같다. 문제는 '언제 바뀌었나'(확인일·시작점)와 그 값을 쓰는 홈 '최근 추세 전환' 목록이다.

## 비교할 방식(고정 — 결과를 보고 더하거나 바꾸지 않는다)
모두 같은 일봉(분할 수정 종가)·같은 σ·같은 h = clamp(10σ, 10%, 35%).

| 이름 | 판정 | 확인일·시작점 |
|---|---|---|
| Z10 현행 | 그날 σ 로 최근 750거래일 창 전체를 지그재그(마지막 다리 방향) | 그날 계산의 마지막 전환점·확정일(매일 다시 그려짐) |
| Z10A 확인일만 바로잡기 | Z10 과 같다 | 확인일 = 날마다 그날까지 자료로 낸 Z10 판정이 마지막으로 바뀐 날(실제로 화면 판정이 바뀐 날). 판정은 그대로라 성과도 그대로 |
| Z10F 앞으로만 | 지그재그 상태(방향·극점)를 날마다 앞으로 굴리고, 그날의 되돌림 판정에 **그날의 h** 를 쓴다. 이미 확정된 전환점은 다시 보지 않는다 | 확정된 그날 그대로(다시 그려지지 않음) |
| Z10L 다리 고정 | Z10F 와 같되 되돌림 판정에 쓰는 h 를 **지금 다리가 확정된 날의 h** 로 고정(다음 전환 때 새 h) | 같음 |

Z10F·Z10L 의 시작: σ 를 잴 수 있는 첫날(500거래일)부터 상태를 굴린다(그 전 고점·저점은 그날부터 다시 잡는다).

## 측정
1. **재현 안정성**(지금 편성·관심·보유 약 100종목, 최근 260거래일): 날마다 그날까지의 자료만으로 계산해 기록하고, 다음 날 계산과 비교한다 —
   판정은 같은데 확인일이 바뀐 수, 시작점이 바뀐 수, 판정 변경 수, 10거래일 안에 되돌아간 판정 변경(되돌림) 수, Z10 과 판정이 같은 날의 비율.
2. **추세추종 성과**(`../trend-follow` 하네스 그대로 — 같은 995종목 유니버스·기간·다음 날 종가 체결·비용·배당 포함 수익): 나라별 동일비중 포트폴리오의
   샤프·연수익·최대 낙폭·보유 비중·판정 변경 횟수와 10거래일 안 되돌림 횟수, 전·후반(경계 2023-04-26).

## 채택 기준(Z10F 또는 Z10L 을 운영 판정으로 바꾸려면 전부)
1. 두 나라 모두 샤프 차(대 Z10) ≥ −0.05, 전·후반 각각 ≥ −0.10.
2. 두 나라 모두 최대 낙폭이 Z10 보다 2%p 넘게 나빠지지 않는다.
3. 두 나라 모두 판정 변경 횟수와 10거래일 안 되돌림 횟수가 Z10 보다 적다.
4. 재현 안정성에서 확인일·시작점 소급 변경 0.
둘 다 통과하면 더 단순한 Z10F. 하나도 통과하지 못하면 **Z10 판정을 그대로 두고 Z10A 를 반영**한다(판정이 같아 성과 검증이 필요 없는 표시 수정 —
확인일·'그 뒤 수익'·홈 '최근 추세 전환' 목록을 실제로 판정이 바뀐 날 기준으로).

## 미리 밝혀 두는 한계
- 성과 표본은 지금 살아남은 대형주(생존편향 — 추세추종에 불리한 쪽).
- 재현 안정성은 지금 종목들만 본다(과거 편출 종목 제외).
- 기준을 통과해도 '앞으로 오른다'는 뜻이 아니다 — 판정 규칙의 일관성과 같은 하네스 성과 비교일 뿐이다.
