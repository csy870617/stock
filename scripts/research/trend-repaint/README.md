사용자 요청: "추세 전환이 뭔가 이상한 것 같아. 다시 한 번 심도 있게 연구하고 수정이 필요하면 수정해줘."
비교할 방식·측정·채택 기준은 결과 전에 `PREREG.md` 에 적고 커밋했다(6cec79b0).

**결론: Z10F(앞으로만 굴리는 지그재그) 채택.** Z10F·Z10L 둘 다 기준 4개를 모두 통과해 사전 규칙대로 더 단순한 Z10F 를 골랐다.

## 원인 — 왜 과거 날짜가 바뀌었나
전환폭 h = clamp(10·σ, 10%, 35%)(σ = 직전 500거래일 일간 로그수익 표준편차)를 **매일 그날 σ 로 다시 정하고 최근 751개 봉 전체를 다시 지그재그로 그렸다.**
σ 가 조금만 변해도 과거 전환점이 생기거나 사라져 시작점·확인일이 소급해서 바뀌고, 가격이 기준가를 넘지 않았는데 판정이 뒤집히기도 했다.

지금 편성·관심·보유 101종목의 최근 260거래일을 날마다 그날까지의 자료로 다시 계산했다(측정 1 — 운영 파일 101/101, git 이력 4,519건 중 4,518건 재현).
- 바뀐 것의 원인(판정 변경·확인일·시작점 변경 701건): **h 변화 386** · 가격 289 · 창 시작 0 · 자료 이상 26(000810·207940·033780·029780·282330).
- 판정은 같은데 확인일이 바뀐 355건과 시작점이 바뀐 27건은 **모두 h 변화** 때문이었다. 판정 변경 319건 중 21건은 가격이 기준가를 넘지 않았는데 h 만으로 뒤집혔다.
- 홈 '최근 추세 전환'(251일 재현): 실제로 바뀌지 않은 줄 123개(3.9%), 날짜가 틀린 줄 121개, 실제 전환이 목록에 없던 날 175개(5.5% — 293번 중 약 20번은 한 번도 안 보임).
  11/6 화면: LMT 는 지난 전환인데 보였고, 207940 은 10/30 으로(실제 10/23), DUK(10/29)·139130(10/26)은 빠져 있었다. 종목 상세 101개 중 30개의 '확인' 날짜가 실제로 판정이 바뀐 날이 아니었다.
- 넓은 표본(측정 2, Z10): 판정이 같은 날 확인일이 바뀐 비율 한국 1.23%·미국 1.48%(종목의 92%·96%가 한 번 이상), 시작점 0.11%·0.12%.
  판정 변경 중 h 만으로 생긴 것 한국 7%·미국 9%, 이 가운데 10거래일 안에 되돌아간 비율 42%·41%(가격으로 바뀐 것 5%).

## 운영 반영 조건 — 이것을 어기면 다시 그려진다
- **고정 시작**: 야후 일봉을 늘 같은 날(2016-11-07, `period1`)부터 받아 500번째 봉부터 상태를 굴린다. 매번 상태 없이 처음부터 다시 계산해도 같은 결과가 나온다.
- 최근 5년(`range=5y`)이나 751개 창 안에서 굴리면 시작이 매일 밀려 다시 그려진다 — 시작을 21·63거래일 늦추면 Z10F 판정이 한국 0.01%·0.06%, 미국 0%·0.02% 종목일에서 달라지고, 다리(전환점·확인일)는 0.3%·0.7~1.4% 에서 달라진다.
- 새 다리의 극점 = 전환점 이후 가장 극단의 종가(측정 2 의 Z10F). 확인한 날 종가를 극점으로 두는 변형(Z10Fa)도 같은 결과(측정 2 샤프 ±0.001, 판정 변경 6,470·9,031).
- 받기에 실패하면 이전 파일을 그대로 둔다(260봉 대체 자료로 계산하면 101종목 중 46종목의 결과가 달라졌다).
- 상장 500거래일 미만이거나 앞으로 굴린 전환점이 아직 없는 종목은 굴릴 수 없어 예전 방식으로 판정하고 '검증 범위 밖'으로 표시, 홈 목록에서 뺀다(11/6 기준 064400 하나 — 2027년 2월 중순 500거래일).
