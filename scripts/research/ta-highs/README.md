## 결론
- '고점의 적극매수가 위험하다'는 자료로 지지되지 않는다 — 고점의 적극매수 뒤 수익·낙폭은 다른 때와 같았고, RSI 70 이상
  과열권은 오히려 조금 나았다(통념의 '과매수 = 매도'와 반대, 다만 전반은 유의하지 않아 '좋다'는 신호로도 쓰지 않는다).
- 그러나 **등급 자체가 이후 수익도 위험도 가르지 못한다** — 적극매도에서 적극매수까지 21일 수익 차이 0.3%p 안, −10% 하락 경험
  42~44%로 같다. '적극매수'라는 이름은 '지금 사면 좋다'는 뜻으로 읽히지만 그 근거가 없다(반대로 '적극매도'도 마찬가지).
  → 등급 계산은 그대로 두고(선정 규칙 동결 대상, 추세 붕괴 결격에 쓰인다) **화면·문장 이름을 추세 상태로 바꾼다**:
  적극매수 → 강한 상승세, 매수 → 상승세, 중립 → 횡보, 매도 → 하락세, 적극매도 → 강한 하락세.
- 종목별 '3개월 −10% 하락 확률'은 보정이 맞지 않아 보이지 않는다(변동성의 평균 회귀·국면 차이 — 이미 검증된 1·3개월 범위를 쓴다).
