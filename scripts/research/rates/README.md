# 정책금리 예측 연구 (2026-10-20)

사용자 요청 "여러 지표와 뉴스를 참고한 금리 예측 모델" — 사전 기준을 정하고 표본 밖으로 검증했다.

- 재현: `node fetch.js <out>` → `node test.js <out>/panel.json --json result.json`
  - 미국 FRED CSV(키 없음), 한국 ECOS(`ECOS_KEY` 없으면 sample 키로 10행씩)·FRED(OECD 실업률).
- 예측 대상: h(3·6·12)개월 뒤 정책금리 − 지금. 확장 창 OLS, 그 시점에 결과가 확정된 표본으로만 추정.
- 모델: M0 변화 없음 · M1 시장 금리 스프레드 회귀 · M2 M1 + 테일러 준칙 갭 · M3 준칙만 (탐색: M1f 기울기 1 고정, M4 한국에 미국 스프레드 추가).
- 사전 기준(M2 채택): 표본 밖 RMSE 가 M1 보다 작고, 앞·뒤 절반 모두 작고, 손실 차이 t ≥ 2.

- 미국은 시장 회귀(M1)가 변화 없음보다 오차 30~40% 작다 → 앱의 미국 예측 = M1.
- 한국은 시장 금리(CD·KORIBOR·국고 1년)로 푼 예측이 변화 없음을 이기지 못했다 → 앱의 한국 예측 = 유지. 프리미엄 고정 방식(`lib-bokpath.js`, M1f)도 3개월 0.49로 더 나빴다 — 그 화면은 '시장 금리에 반영된 기대'로만 읽는다.
- 탐색(사전 기준 밖): 한국 12개월에 미국 스프레드를 더한 M4 가 0.915(앞 1.033·뒤 0.779)로 변화 없음보다 조금 나았지만 3·6개월은 나빴다 — 채택하지 않고 기록만 남긴다.
