# 정확도 연구 (2026-10-16)

`CLAUDE.md` §7 '정확도 연구'와 `docs/HISTORY.md` 2026-10-16 항목에 있다. 캐시 디렉터리(기본 `research-cache`)는
`../leading/fetch-universe.js`(가격 `px/`·유니버스)와 `../leading/fetch-flow.js`(한국 수급 `flow/`)가 먼저 만든다.

| 스크립트 | 무엇 | 결론 |
|---|---|---|
| `engine-components.js` → `comp-ic.js` | 현행 엔진 구성요소(이평·일목·매물대·보조, 일·주·월)·mtf 점수·매물대 원재료·한국 수급의 날짜별 횡단면 IC(지수 초과, 전·후반) — 넓은 표본 881종목과 편성 이력(`--roster`) 비교 | 넓은 표본은 전부 IC 0 근처. 편성 이력에서만 장기(월봉) 양(+) — 사후 선택 효과로 판단, 재가중 기각 |
| `vp-levels.js` | 1년 매물대의 거래 집중(HVN)·희박(LVN) 가격에 1개월 안 처음 닿은 뒤 5·10일 반응(환경변수 `BINS`·`LB`·`HT`·`LT` 로 설정 변경) | 지지·저항 효과 없음(4개 설정 동일) |
