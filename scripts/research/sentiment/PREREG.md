# 시장 심리 온도계(공포 ↔ 환호) — 사전 등록 (2026-11-06, 결과를 보기 전에 고정)

## 질문
사용자(2026-11-06): "주가를 분석하고 예측할 때 대중의 심리를 잘 이용할 수 있어야해. 이동평균선과 매물대, 공포와 환호 등 대중의 심리까지 함께 분석되면 좋겠는데" → 제안한 '시장 공포·환호 온도계'를 "1번부터 진행해줘".

이동평균선·매물대·과열 지표(RSI 등)와 종목 단위 심리 지표(머리 위 매물 비중·거래량 급증·이격도·반전·모멘텀)는 이미 시험해 기각했다(CLAUDE.md §7). 여기서는 **시장 전체의 분위기**를 하나로 묶은 점수가 ①지금 분위기를 보여 주는 사실 표시를 넘어 ②앞으로의 지수 수익·급락을 가르는지를 묻는다.

예전 유동성 게이지(금리 수준·VIX·하이일드·달러·코스피 모멘텀을 손으로 정한 문턱으로 합친 것)는 2026-10-30 연구에서 예측·하락 위험 모두 미달이었다(`scripts/research/liquidity/`). 이번 점수는 VIX·모멘텀을 다시 쓰지만 ①문턱 대신 각 지표의 직전 5년 백분위 ②시장 폭·안전자산 선호·신용융자·외국인 수급 같은 새 재료 ③**극단 구간만 보는 가설**이 다르다. 사전 판단: 예전 게이지가 떨어진 걸 보면 통과 가능성은 높지 않다 — 그래도 같은 저울로 정직하게 잰다.

- 월말 점수 → 다음 h개월(h = 3·12) 누적 초과수익: 미국 SPY 수정종가(배당 포함) 월간 수익 − 전월말 3개월 국채(DTB3)/12, 한국 코스피 월간 수익 − 전월 CD 91일(ECOS)/12.
- 급락: 다음 63거래일 안에 월말 종가 대비 −10% 이하로 내려간 적이 있나(미국 SPY 수정종가, 한국 코스피).
- 끝난 달까지만(2026-10). 전·후반 = 점수와 3개월 수익이 모두 있는 달을 순서대로 반으로 나눈 경계.

## 가설과 판정(나라·기간마다 따로)
| 가설 | 내용 | 통과 기준 |
|---|---|---|
| H1 | 점수가 높을수록(환호) 다음 h개월 초과수익이 낮다 — 점수 ÷ 100 에 대한 기울기 | 뉴이-웨스트 t(시차 h+1) ≤ −2 · 전반·후반 기울기 모두 음 · 표본 밖 R² > 0(확장 창, 미국 2005-01·한국 2014-01부터, 결과가 끝난 쌍만으로 맞춘 회귀 vs 과거 평균, 학습 쌍 36개 이상·표본 밖 달 24개 이상) |
| H2 | 극도의 공포(점수 < 20) 뒤 다음 h개월 초과수익이 나머지보다 높다 | 차이 > 0 · 0/1 회귀 NW t(시차 h+1) ≥ 2 · 전반·후반 차이 모두 양 · 차이 ≥ +2%p(3개월)·+5%p(12개월) · 반쪽마다 해당 달 6개 이상 |
| H3 | 극도의 환호(점수 ≥ 80) 뒤 다음 h개월 초과수익이 나머지보다 낮다 | 차이 < 0 · NW t ≤ −2 · 전반·후반 모두 음 · 차이 ≤ −2%p(3개월)·−5%p(12개월) · 반쪽마다 6개월 이상 |
| H4 | 극도의 환호 뒤 3개월 안 −10% 급락 확률이 나머지보다 높다 | 전반·후반 차이 모두 +5%p 이상 · 0/1 차이 NW t(시차 3) ≥ 2 · 반쪽마다 6개월 이상 |
| H5 | 극도의 공포 뒤 3개월 안 −10% 급락 확률이 나머지보다 높다(변동성 뭉침) | 같은 기준 |

- 시험 수가 많다(나라 2 × 가설 5 × 기간 1~2 = 16개). 하나만 통과한 것은 우연일 수 있다는 점을 결과에 함께 적는다.
- 보조(판정에 쓰지 않음, 결과에 그대로 보고): 지표 하나씩의 같은 시험, 모든 지표가 있는 달만의 같은 시험, 다섯 구간별 다음 3·12개월 평균 초과수익과 급락 비율.

## 반영 규칙(사전 고정)
- 통과 여부와 상관없이 앱에 **지금 분위기(사실)** 로 보인다: 점수·구간·구성 지표의 지금 값과 백분위·5년 추이. '예측'이라 부르지 않는다.
- 나라·기간별로 통과한 가설만 그 나라 화면에 검증 문장을 붙인다 — H2 통과: '극도의 공포' 구간에서 과거 다음 h개월 평균 초과수익(나머지와 비교)·달 수, H3·H4: '극도의 환호'에서 같은 식, H5: '극도의 공포'에서 급락 비율, H1: '점수가 높을수록 이후 수익이 낮은 경향(검증 통과)'.
- 통과하지 못하면 ⓘ 에 '과거 시험에서 앞으로의 수익·급락을 가르지 못했다 — 지금 분위기를 보는 용도'라고만 쓴다. 구간별 과거 평균 숫자는 보이지 않는다.
- 종목 선정 규칙은 바꾸지 않는다(동결 2026-10-21~2027-01-21).
- 같은 가설을 정의만 바꿔(창 길이·구간 문턱·지표 구성) 다시 시험하지 않는다. 판정 뒤 탐색은 README 에 '사후'로만 적는다.
